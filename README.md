# Customer Churn Analysis

This project explores telecom customer churn using Python and data visualization to understand patterns associated with customers leaving the service.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Covered
- Customer churn distribution
- Churn by senior citizen status
- Churn across phone and internet services
- Churn across security, backup and technical support services

## Project Files
- `churn_analysis.ipynb` — Analysis code and visualizations
- `Raw data for churn analysis.csv` — Dataset
- `Teco Customer Churn Analysis.pdf` — Project report

## How to View
Open the notebook on GitHub to see the code and saved charts, or download the PDF report.
